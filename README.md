# NearLoop 在地二手交易平台

NearLoop 是一個在地化二手物品交易平台第一版網站原型，主打步行可達、純面交、模糊定位與 QR Code 完成交易。

## 功能

- 聚合式搜尋：關鍵字、步行時間、方圓距離、價格區間
- 商品瀏覽：分類、商品卡片、商品詳情、賣家評分
- 隱私位置：前台只顯示概略區域與模糊範圍
- 站內聊天：快捷訊息與照片入口示意
- 交易確認：QR Code 完成交易並更新狀態
- 賣家刊登：拍照刊登、分類、面交規則
- 管理後台：上架物件、售出、檢舉與營運指標

## 本機執行

```bash
npm install
npm run dev
```

開啟瀏覽器：

```text
http://localhost:5173/
```

## 建置

```bash
npm run build
```
